# TidalMpvPlayer

Drop in replacement for Tidal's native player executable, using MPV as the backend.

Allows for custom functions like crossfade, visualisers, EQ, etc. inside tidals official client.

**This project does nothing on it's own. If you do not know what this is, you probably don't need it and cant get it to run.**
